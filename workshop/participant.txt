PARTICIPANT GUIDE
=================
Story: a student of CS 329Z: Engineering AI Agents wants to know what is new for the coming lectures. A smart "lead" model
reads the course schedule and picks the topics, small "worker" models search the web; all inside an OpenShell sandbox.
One notebook shows how the agent works and how OpenShell controls it (28 checks, audit log).

You get from the instructor: the image address, NEBIUS_API_KEY, TAVILY_API_KEY.
You make up yourself: JUPYTER_TOKEN, the password of your Devlab (16+ random characters: openssl rand -hex 16). Write it down.

1. CREATE A DEVLAB   console -> Serverless AI -> Devlabs -> Create (field names may differ a little)
     Image: the address   Port (HTTP): 8888   Workspace path: /workspace   Machine: cpu-d3 4vcpu-16gb, 100 GiB   Public IP: yes
     Variables: JUPYTER_TOKEN, NEBIUS_API_KEY, TAVILY_API_KEY (secret-type if offered; never put keys in a notebook, file or chat)
   Wait for RUNNING (3-4 min), open the URL, enter your token.

2. LOAD THE CODE   File -> New -> Terminal:
     cd /workspace && curl -fsSL https://github.com/dashabalashova/agents-openshell-workshop/archive/refs/heads/main.tar.gz | tar xz --strip-components=2 --wildcards '*/workshop/*'

3. RUN   radar-openshell.ipynb -> Run All Cells (1-3 min). Success: "TOTAL: 28/28 checks passed".
   Read: 5a findings | 5b who did what | 5c checks | 6 audit log.

4. TRY   Edit sandbox/policy.yaml, run case.up() (section 4), re-run from section 5. Which check fails?

5. FINISH   Run case.down() (last cell), delete your Devlab.

PROBLEMS
  "keys not set"             a variable is missing or misspelled in the Devlab settings
  model timeout              run the cell again
  "sandbox was not created"  run case.down(), then section 4 again
  broke a file               repeat step 2 (copy sandbox/policy.yaml first to keep it)
  anything else              ask the instructor
