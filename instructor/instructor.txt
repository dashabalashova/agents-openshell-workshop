================
A smart "lead" model plus small "worker" models search the web inside an OpenShell sandbox; one notebook shows the agent and OpenShell (28 checks, audit log).
Code: https://github.com/dashabalashova/agents-openshell-workshop (workshop/). Participants follow workshop/participant.txt. Run everything from this folder.

SECRETS (you create them; keep them only in config.env)

  NEBIUS_API_KEY   https://tokenfactory.nebius.com -> create an API key (a separate one for the workshop; revoke it afterwards)
  TAVILY_API_KEY   https://app.tavily.com -> API key (tvly-...); the free plan has 1,000 credits/month: 1 run = 6 searches
  PROJECT_ID       Nebius project id (nebius config get parent-id)

                                 Run it after step 2a and after every new image or code on GitHub. It does not test the console form.
