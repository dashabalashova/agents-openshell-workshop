INSTRUCTOR GUIDE
================
Run everything from this folder. Participants follow ../workshop/participant.txt.

SETUP (once)
  Tools: nebius CLI (logged in), jq, rsync, python3, ~/.ssh/id_ed25519.pub
  cp config.env.example config.env, then fill it:
    JUPYTER_TOKEN    your Devlab password (openssl rand -hex 16)
    NEBIUS_API_KEY   https://tokenfactory.nebius.com -> API key (a dedicated workshop key; revoke it afterwards)
    TAVILY_API_KEY   https://app.tavily.com -> API key (free plan: 1,000 credits/month; one run = 6-9 searches)
    PROJECT_ID       nebius config get parent-id

STEPS
  1  ./1-build-image.sh      ~10 min  image -> registry (:latest). --delete removes the registry.
  2  ./2-create-devlab.sh    ~4 min   your Devlab from :latest. --delete removes it.
  3  ./3-check-devlab.sh     ~2 min   tools/verify.py does what a participant does and checks 10 results (expect 10/10, notebook 28/28).
  DRY_RUN=1 makes steps 1 and 2 only check.  tools/devlab-image/ is the image source (JupyterLab + OpenShell 0.1.1 + Docker).

HAND OUT (privately)
  cp handout.example.txt handout.txt, fill in the image address and the keys (never commit), send it with the participant guide.

SESSION (90 min)
  10 threat model | 15 create Devlabs | 25 the agent | 25 OpenShell (policy, checks, audit) | 20 hands-on | 5 wrap-up
  Hands-on: allow arxiv.org -> its check FAILS; allow GET /search -> "denied method" FAILS; drop POST /v1/chat/completions -> the agent stops.

RISKS
  A Devlab URL is public, protected only by its token: one token per participant, never on screen.
  Before the day: nebius login valid; Tavily credits cover participants x runs; participants' project can pull the image;
  create one Devlab through the console by hand (form field names are not verified).

STATUS (2026-11-16)

  Not verified: the console form, many participants at once, finding quality, cost saving of the small model.
